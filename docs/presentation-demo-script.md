# 3-minute software demonstration

1. Open Dashboard.
2. Explain the flow strip: Detect → Identify → Predict → Deter → Observe → Adapt → Verify → Learn.
3. Click **Simulate Intrusion**.
4. Show Wild Boar / North-West / Deterrence Active / Retreat Confirmed.
5. Open Events to show the detection and intervention timeline.
6. Return to Dashboard and click **Simulate No Response**.
7. Show that two intervention records appear: first `no_response`, second `retreated`.
8. Open Validation and enter the real feedback from tester 1, 2, and 3.
9. Explain that the software is a 35% prototype and real field metrics are measured only after testing.
